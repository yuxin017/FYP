TRY THESE IN ORDER
1. Profile > Help & Support. Search for tickets or points. Open Tutorials &
   User Guides, change categories and open a guide. Try Previous/Next and the
   FAQ links. Open FAQ, search for a phrase, change category and expand answers.

2. Open Submit Feedback, Report a Problem and Submit a Complaint. Each opens
   the appropriate tab. Try submitting an empty form: field validation appears.
   Enter your own subject and message, select a category and optionally attach
   a JPG, PNG or PDF. Attachments are limited to 500 KB; larger photos are resized.
   For Tickets & Admission or Payments & Billing, an owned booking is optional.

3. Send one request you want to keep. The contact checkbox is optional; it
   shares your account email with support when selected. In-app replies work
   either way. Confirmation shows a saved reference and opens View Request.
   Refresh, return to My Requests and check that the request remains saved.
   If a connection is interrupted, Retry Submission reuses the same reference.
   A pending submission also restores when the form is reopened.

4. Open the administrator portal > Feedback & Complaints. Your request should
   appear. Try the search and filters, then open its case panel. Review the
   attachment or related booking if supplied. Assign it to yourself, change
   priority/category/status and Save Changes. Changes appear in the timeline.

5. Add an Internal Note. Switch back to the visitor: that note must not appear.
   In the admin Details tab, choose a response template, edit it and Send Reply.
   The template fills the composer; choosing one alone does not send a message.
   The visitor should see the actual reply and be able to send a follow-up.

6. As admin, resolve the case with a resolution summary. The visitor sees the
   summary and Resolved status. As visitor, choose Reopen Request, then send a
   follow-up. History stays visible and the case returns to In Progress.
