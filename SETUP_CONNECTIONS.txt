RESERVATION NOTIFICATIONS
No new paid service is required. Native Android/iOS use scheduled local
notifications; supported browsers use Web Push from the existing Node backend.
The backend creates signing keys once in the protected serverConfiguration/
reminders document. Only its public key is returned to authenticated visitors;
private keys and browser subscription endpoints are never part of the client
bundle or Git. Another PC loads these settings from the shared project.

Profile -> Security & Account -> Notifications: allow notifications on this
device. Android also requests Alarms & reminders access for timed delivery.
Choose Notify Me on reservation review, or use the My Reservations switch.
Disabling reminders or signing out clears this device's scheduled reminders.
Browser sending checks the actual reservation/account and skips cancellations,
expired windows, closed/restricted accounts and revoked device sign-ins.
Native schedules are updated when this device receives reservation changes;
changes made elsewhere while the app is closed sync on its next launch.

The Android manifest includes scheduling and reboot receivers. Exact delivery
still depends on OS permissions, power management and Focus settings. An app
that is force-stopped may need to be reopened. On iOS, build/sign on a Mac and
verify permission/delivery on the chosen iPhone. This was not tested on a Mac.
Web Push needs HTTPS or localhost/127.0.0.1, internet, the running Node service
and an available browser background notification service. Closing the tab is
supported; fully shutting down the browser/PC can prevent timely delivery.
https://pub.dev/packages/flutter_local_notifications/versions/19.5.0
https://developer.mozilla.org/en-US/docs/Web/API/Push_API

WEATHER BENEFITS / LOYALTY
On 10 November 2026 the user enabled and saved weather benefits: TAR UMT Penang,
2 mm threshold, one complimentary drink at the park café and 30-day validity.
The configuration was read back from Firebase. The latest weather record was
from Open-Meteo with 0 mm precipitation and rainQualified=false; a real rain
voucher and counter redemption have not been verified through the live app.
Admin -> Promotions & Rewards -> Weather Benefits: set the real park name,
latitude/longitude, precipitation threshold and the benefit you actually honour.
Enable only after reviewing those settings. The connector uses current
Open-Meteo model-based weather information, not invented on-site measurements.
Once enabled, the running API checks weather and issues one voucher per eligible
ticket-owning visitor for the affected day. Weather fetches are cached for 15
minutes; bounded issuance batches run every minute and resume with a private
cursor. Late purchases and closing/restricted accounts are excluded. A visitor
can also open Park Offers to retrieve the same voucher without receiving a copy.
https://open-meteo.com/en/docs
No-show deductions remain disabled unless enabled by an administrator; their
effective date prevents retroactive deductions. Points never fall below zero.
Purchase earning rates are snapshotted on confirmed orders.

Admin -> Crowd Monitoring refreshes queue demand every 30 seconds. Its heatmap
uses confirmed places in today's remaining return windows. Hourly peaks and
journey counts use actual staff check-ins. Journeys require the same admission
pass reference and check-ins within three hours on the same day. No continuous
GPS movement is invented when venue positioning has not been configured.

NFC AND PRINTING
Android pass sharing uses a read-only NFC Forum Type 4 NDEF text record, AID
D2760000850101. The phone must support HCE, be unlocked and have NFC enabled.
Pass sharing expires after one minute. Android staff devices can read those
passes; desktop kiosks can use compatible NDEF readers configured as keyboards.
PC/SC-only readers need their vendor's keyboard/bridge software. QR remains an
available entrance/collection method. Hardware was not connected for this work.
Connect a printer with the correct 6x8 or 8x10 paper/finish. The kiosk generates
one actual PDF page per copy and opens the OS print dialog. Confirm that the
job was sent, then confirm physical collection. Cancelling does not collect it.
https://developer.android.com/develop/connectivity/nfc/hce

CURRENCY CONFIRMATION
Select MYR/USD/SGD/CNY/EUR from the Tickets hub. Foreign prices use dated daily
