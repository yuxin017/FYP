Run FYP on another Windows PC

1. Install Git for Windows if needed, then open PowerShell.

2. For a new copy, run:

   git clone --branch feat/a-foundation https://github.com/yuxin017/FYP.git
   cd FYP
   .\tool\run-app.cmd

   For an existing copy, open PowerShell in your FYP folder and run:

   .\tool\stop-app.cmd
   git fetch origin
   git switch feat/a-foundation
   git pull --ff-only origin feat/a-foundation
   .\tool\run-app.cmd -Restart

3. If startup stops with "Would change 4 dependencies" or
   "Unable to satisfy pubspec.yaml using pubspec.lock", run:

   $fypRuntime = Get-Content .\.local\runtime.json | ConvertFrom-Json
   & $fypRuntime.flutter --no-version-check pub get
   .\tool\run-app.cmd

4. If prompted, sign in with a Google account that has access to
   the Firebase project themeparksmartmanagement.

5. Wait for "Account services ready" and "is being served".

6. Keep PowerShell open and open one of these links:

   Visitor  http://localhost:5173/
   Admin    http://localhost:5173/#/admin
   Kiosk    http://localhost:5173/#/kiosk

7. To stop the app, open PowerShell in the same FYP folder and run:

   .\tool\stop-app.cmd

If a page says "Unable to connect", open a second PowerShell window and run:

   Invoke-RestMethod http://127.0.0.1:8787/health

Look for ok=True. If the check fails, send the first error from the launcher.
